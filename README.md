# UNI-PARK 🚗🅿️

Sistema web de gestión de parqueadero desarrollado para digitalizar el funcionamiento del proyecto original en Java Swing.

## Descripción
UNI-PARK es una aplicación web para controlar el ingreso y retiro de vehículos, gestión de reservas, incidencias y visualización de registros mediante una interfaz moderna y accesible.

La app fue adaptada para funcionar en navegador con una base de datos local SQLite y una estructura protegida por login.

## Características principales
- Registro de ingreso y salida de vehículos
- Control de reservas y horarios
- Visualización de vehículos registrados
- Gestión de incidencias
- Sistema de autenticación y acceso protegido
- Diseño moderno con identidad institucional

## Tecnologías utilizadas
- Node.js
- Express
- SQLite
- HTML, CSS y JavaScript

## Inicio rápido
1. Instala dependencias:
   ```bash
   npm install
   ```
2. Inicia la aplicación:
   ```bash
   npm start
   ```
3. Abre en el navegador:
   ```text
   http://localhost:3000
   ```

## Acceso de prueba
- Usuario: `admin`
- Contraseña: `1234`

## Estado
Proyecto convertido a versión web, con login, protección de rutas y base de datos local funcionando.
